# Jogo da Velha

**Desenvolvido por: Ninjaagoo**

Este jogo de tabuleiro foi feito para estudar e aprender a linguagem C.

<img src="slaLegal.jpg" alt="Pelúcia com fones de ouvido e gorro" width="250">

## Executar

Abra o terminal na pasta do jogo. Com o GCC instalado, digite:

```powershell
gcc jogo_velha_10.c -o jogo_velha_10.exe
.\jogo_velha_10.exe
```

## Jogar

- Pressione **Enter** para abrir o menu.
- Digite `1` para jogar. O modo inicial é para dois jogadores.
- Para jogar contra o computador, escolha `2` no menu e depois `1` nas configurações.
- Digite a linha e a coluna da jogada, usando números de `0` a `2`.
- No menu, `3` mostra o placar e `4` sai do jogo.
